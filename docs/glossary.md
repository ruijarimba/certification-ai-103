# Glossary

This glossary defines shared terms used across the AI-103 study notes.

## Terms

| Term | Meaning |
| --- | --- |
| AI-103 | Microsoft certification for Azure AI Apps and Agents Developer Associate. |
| Azure AI Foundry | Microsoft platform for building, evaluating, and managing AI apps and agents. |
| Azure AI Services | A family of Azure services for language, speech, vision, document processing, safety, and related AI capabilities. |
| Azure OpenAI Service | Azure service that provides access to OpenAI models with Azure security, networking, and management features. |
| Azure AI Search | Azure search service used for keyword, vector, hybrid, and semantic search scenarios. |
| Microsoft Learn | Microsoft documentation and training site. Use it as a source, but summarize in original words. |
