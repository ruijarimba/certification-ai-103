# AI-103 (Azure AI Apps and Agents Developer Associate)

This repository contains study notes for the Microsoft AI-103 certification. The focus is the certification content: Azure AI concepts, services, relationships, and module-based notes.

The repository does not copy Microsoft Learn content. Short service summaries are allowed when they are written in original words and link to the official source.

## Folder structure

```text
.
├── .github/
│   ├── copilot-instructions.md
│   └── instructions/
├── docs/
│   ├── azure-services/
│   ├── modules/
│   ├── references/
│   ├── glossary.md
│   └── progress.md
├── infra/        # Reserved for future Terraform or deployment examples.
├── src/          # Reserved for future code samples or lab helpers.
└── README.md
```

## Documentation areas

- `docs/modules/` contains certification content grouped by module, using numbered folders such as `01-plan-and-manage-an-azure-ai-solution/`.
- `docs/azure-services/` contains one page or folder for each relevant Azure service, including purpose, relationships, and certification notes.
- `docs/references/` contains reusable comparisons, service relationship notes, limits, and diagrams.

The `src/` and `infra/` folders are planned future areas. They should stay absent or minimal until the repository needs code samples, lab helpers, or infrastructure examples.
